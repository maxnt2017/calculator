🧠 Математичний Порадник & Правила

🚫 1. Чому на 0 ділити не можна? ▼

Ділення є операцією, оберненою до множення. Вираз a ÷ b = c означає, що c × b = a. Якщо b = 0, то для будь-якого числа c × 0 = 0. Отже, якщо a ≠ 0, такого числа c не існує в природі.

📐 2. Корінь парного степеня з від'ємного числа (√-x) ▼

Квадрат будь-якого дійсного числа завжди невід'ємний (x² ≥ 0). Тому операція √(-9) не має розв'язку серед дійсних чисел ℝ. Для розв'язання використовують уявну одиницю i = √(-1).

📉 3. Логарифм від'ємного числа або нуля ln(x ≤ 0) ▼

Логарифм log_b(x) = y запитує, в який степінь піднести b > 0, щоб отримати x. Оскільки додатне число у будь-якому степені завжди додатне, аргумент логарифма має бути строго додатним x > 0.

⭕ 4. Межі тригонометричних функцій arcsin та arccos ▼

Оскільки значення синуса та косинуса лежать суворо у межах [-1; 1], обернені функції asin(x) та acos(x) визначені лише тоді, коли |x| ≤ 1.
